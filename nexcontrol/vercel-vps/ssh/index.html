Récupérer mon VPS

Accès direct au port SSH de ton serveur, même si l'ancien agent NexControl est hors ligne. Ce formulaire exécute une commande par requête et n'est pas une session de terminal interactif persistante.

Activer l’accès SSH sécurisé

Cette étape se fait une seule fois dans Vercel, sans connexion préalable au VPS. Le nouveau code administrateur n'est pas ton mot de passe Linux.

1. Copie ce code. 2. Dans les variables de production de Vercel, ajoute NXC_SSH_ADMIN_TOKEN avec cette valeur (type Sensitive). 3. Redéploie le projet. 4. Reviens ici et utilise le code dans le champ « Connexion administrateur ».
